# Resource_Editor
一、它是做什么的
这是基于 Godot 4 开发的一款可视化游戏资源（道具/物品）数据编辑器。它让策划/美术/运营人员不用碰代码，就能通过图形界面定义、编辑并导出游戏里的各种物品数据（食物、种子、工具、武器等）。
二、核心工作流
模板脚本定义 → 可视化编辑 → 数据持久化 → 游戏端加载
1. 模板驱动的字段自动生成
每种资源类型（FoodResource、SeedResource、FurnitureResource 等）由 .gd 脚本定义字段。
编辑器自动扫描模板脚本，用反射（get_property_list）读取字段元数据，自动生成对应的编辑控件：
文本 → 文本输入框
数值 → 数字微调框（SpinBox）
布尔 → 开关
枚举 → 下拉菜单
贴图 → 贴图选择器（可弹文件框选图片）
资源引用 → 资源选择器（选其他 .tres）
新增一种资源类型，只需写一个脚本，UI 自动适配，无需改编辑器代码。
2. 数据编辑与持久化
左侧：当前类型的资源列表（可切换、高亮选中）。
右侧：选中资源的字段详情编辑区。
自动保存（防抖系统）：编辑字段后停顿 1.5 秒自动落盘，防抖期内继续编辑则重置计时，避免频繁写盘；切换资源/退出时自动补存。
支持新建、清除（保留 id/data_name 身份标识，清空其余字段）、保存。
数据以 .tres 文件持久化到用户可写目录。
3. 游戏端数据导出
一键导出所有资源到 game_data.dat（Godot 序列化字典）。
结构按 类型 → id → {id, data_name, 各字段} 分层，贴图自动转为路径字符串（不内嵌图片，减小体积）。
数据 + 模板脚本都写入用户目录，可脱离编辑器环境独立运行。
